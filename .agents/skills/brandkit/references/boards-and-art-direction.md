# Boards and art direction

A board should explain an identity at a glance. Use a clear hierarchy, generous breathing room, and a limited vocabulary carried across applications. Choose the number of panels for the requested content; these are layout options, not quotas.

## Composition options

- A compact board can show the primary mark, wordmark, palette, typography, one application, and one image treatment.
- A larger identity board can add inverse marks, geometry, pattern, packaging, or product UI where useful.
- A 2×3 or 3×3 grid can organize multiple applications, but merge or omit panels when the content needs room. Do not shrink essential text to satisfy a grid.
- Let a strong mark or application lead; supporting panels should clarify the same concept rather than introduce unrelated aesthetics.

## Visual modes

| Direction | Palette and material | Suitable applications |
|---|---|---|
| Developer or operator | Dark neutral, precise type, restrained signal color | CLI, dashboard, documentation |
| Nature or wellness | Earth tones, organic detail, tactile paper | Packaging, editorial, app |
| Security | Controlled geometry, quiet contrast, robust type | Product surfaces and trustworthy documentation |
| Editorial | Distinctive type, off-white, considered image crops | Publication, portfolio, cultural work |
| Luxury | Sparse composition, material contrast, disciplined mark scale | Print, packaging, environments |
| Voice or consumer | Warmth, expressive imagery, approachable forms | App, social, service touchpoints |
| Cultural | A concept rooted in the actual work or place | Posters, tickets, publication |

These are optional directions. Existing colors, fonts, logos, and audience needs override category defaults. Security styling does not authorize claims of certification; developer styling does not require fake terminal output.

## Prompt structure

Describe the brand and one-sentence concept, the actual supplied assets, requested board format, chosen palette and typography character, key applications, and legibility priorities. State exact text only when necessary and available. Keep supporting captions sparse; omit unreadable microcopy rather than fill the board with invented facts.

For mockups, use consistent lighting, material, and perspective. Make the identity legible before adding cinematic atmosphere. After generation, inspect spelling, mark consistency, palette, and panel readability. Correct a concrete defect with a targeted edit or regeneration rather than producing extra boards for variety alone.
