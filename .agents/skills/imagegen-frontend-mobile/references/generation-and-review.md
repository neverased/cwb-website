# Mobile generation and review

Prompt with the platform, screen purpose, supplied references, selected visual system, content hierarchy, exact authorized copy, safe areas, and requested framing. State the requested screens and output format clearly. Do not add a default flow, extra variants, or new device angles without a reason tied to the deliverable.

Use the tool's actual reference inputs for edits and continuity. Inspect the output for platform coherence, safe areas, text readability, icon consistency, navigation, content hierarchy, and cross-screen data consistency. A static mockup cannot verify touch behavior, accessibility semantics, or implemented motion; describe them as intended behavior when relevant.

Correct concrete defects through a targeted image edit or regeneration. If inspection zoom resolves uncertainty, use it before producing more images. Stop when the requested screens communicate the design clearly, without unresolved material defects. Do not run an unbounded regeneration loop seeking marginal aesthetic improvements.

Deliver actual images or returned artifact paths using the available tool's output mechanism. State any remaining legibility or source limitations. Do not claim code, a simulator run, or a working flow when only image concepts were produced.
