# Signal redesign — implementation and verification

The approved Signal concept is implemented in the public website. It keeps the
graphite/mint identity, Space Grotesk and Fira Code, original portrait, React Bits
Lanyard and authentic collaboration marks.

## Delivered behavior

- Larger two-line hero, clearer introduction, primary contact action and one
  expertise entry point. The repeated six-service list on the homepage is gone.
- Three needs organize all six existing specialties: review a system, build a
  product and get technical direction. Specialty IDs and contact destinations
  remain unchanged. Deep links and browser history restore the selected service.
- A restrained signal trace connects the active choice to the result. A local
  pointer light operates only on the service panel for fine mouse pointers.
- Collaboration logos share compatible dark/light surfaces with optical sizing.
  They remain labelled “Selected collaborations”; no project results were invented.
- A four-stage process timeline works horizontally on desktop and vertically on
  phones. The detailed process page keeps its existing inputs, outputs and handoff
  artifacts. Contact callouts expose direct email and the existing form.
- Motion uses CSS and Web Animations alongside the existing Three.js Lanyard;
  no new animation dependency was added. Reveals are finite and content is visible
  in the initial HTML.
- A global Motion toggle persists pause in session storage and follows live OS
  reduced-motion changes. Global resume respects the card's separate local pause.
  Pausing unmounts the renderer and cancels active reveals; blocked storage does
  not prevent the control working.
- Native links, keyboard card flipping, mobile navigation, portrait fallbacks,
  form protections, private quotes and original artwork are retained.

`DESIGN.md` and the tracked Impeccable sidecar now describe the current Signal
system. The older HUD design documents remain historical context.

Small header, specialty and footer hit areas were increased to at least 44px.
Testing with a 200% root text size exposed overflow in the header, long labels,
email and card controls. Flexible wrapping and long-word handling correct these
cases without reducing the requested text size.

The development resource named after Lanyard is a 933-byte Turbopack loader stub,
not the renderer. Its presence is not evidence that Three.js was downloaded.
The production network check identified the actual renderer chunk from its build
contents before asserting its absence for reduced-motion visitors.

## Scoped design audit

The result follows the approved personal/technical direction: real portrait,
plain service outcomes, restrained signal lines, existing typography and brand
colors. It introduces no invented metrics, generic dashboard decoration or
additional dominant shader.

| Dimension          | Score | Evidence and boundary                                                                          |
| ------------------ | ----- | ---------------------------------------------------------------------------------------------- |
| Accessibility      | 3/4   | Keyboard/menu/pause/fallback behavior checked; no formal screen-reader certification           |
| Performance        | 3/4   | Deferred renderer, finite UI motion and local pointer updates; physical devices not profiled   |
| Responsive design  | 4/4   | Five viewport sizes, touch controls and enlarged-text correction                               |
| Theming            | 3/4   | Current tokens documented; artwork and physical card materials retain intentional fixed colors |
| Visual consistency | 4/4   | Approved Signal composition, authentic proof and one coherent motion language                  |

This scoped assessment is **17/20**, not a full WCAG or performance certification.
Independent code review found a visible/accessibility-name mismatch on Motion;
the name now includes the visible word. Other observed issues were fixed during
verification rather than left as recommendations.

The scoped deterministic detector has no remaining findings after refreshing the
design documentation and recording two exact `design-system-color` exceptions:
`#000` is an opaque CSS mask stop, and `#0009` is the documented physical card
shadow. These are recorded with reasons in `.impeccable/config.json`; no detector
rule or file is disabled.

## Limits and local state

- The local PostgreSQL service at port 54329 was not running. Notes/CMS requests
  (including framework prefetches) therefore log connection refusals. CMS-backed
  content, quote HTTP/database flows and publishing were not verified here.
- Build warnings for `metadataBase` and duplicate macOS libvips libraries also
  occurred before this redesign. They remain separate from the changed UI.
- No real contact email was sent. No database records, production settings,
  remote branches or releases were changed. The changes are prepared as local
  commits; no deployment was made.
- Browser checks used emulated mobile/touch conditions. Real-device GPU behavior,
  Safari/Firefox and field Core Web Vitals remain unmeasured.

Local production preview: `http://127.0.0.1:3000/` while the started server is
running. Recreate it with `pnpm build` followed by
`PORT=3000 HOSTNAME=127.0.0.1 pnpm start`.
