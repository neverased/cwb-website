# Quote PDF fonts

Space Grotesk Regular and Bold are bundled for server-side PDF rendering, including
Polish characters. Rendering never downloads fonts or depends on system fonts.

Source: https://github.com/floriankarsten/space-grotesk/tree/master/fonts/ttf/static

- `SpaceGrotesk-Regular.ttf`: upstream Git blob `46aa5dada9c4833e55256a4f3437388f42c5f666`
- `SpaceGrotesk-Bold.ttf`: upstream Git blob `f8eb245d1ec7fd02d77f5a9b55ef6afc4c9ed1c1`
